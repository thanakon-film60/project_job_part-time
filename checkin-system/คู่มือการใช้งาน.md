# คู่มือการใช้งานระบบเช็คอิน MARDODI

เอกสารนี้สรุปวิธีเข้าใช้งานระบบ, รหัสทดสอบสำหรับหัวหน้า/พนักงาน, และ path ที่เปิดเข้าได้ทั้งฝั่งหน้าเว็บและ API

## ลิงก์เข้าใช้งาน

| แบบใช้งาน | URL / path | ใช้ทำอะไร |
|---|---|---|
| เว็บจริง | `https://thanakronpart-time.com` | หน้าเว็บหลักสำหรับล็อกอิน ดูปฏิทิน และประวัติใบหน้า |
| เว็บจริงแบบ www | `https://www.thanakronpart-time.com` | ชี้เข้าระบบเดียวกัน |
| API โดเมนจริง | `https://api.thanakronpart-time.com` | เรียก API path เช่น `/auth/login`, `/reports/calendar` |
| เว็บ dev บนเครื่อง | `http://localhost:5173` | หน้า React ตอนรัน local |
| API dev บนเครื่อง | `http://localhost:8002` | Backend ตอนรัน local ตาม `RUN_LOCAL.md` |
| API docs dev | `http://localhost:8002/docs` | เอกสาร API แบบ Swagger |

ถ้าใช้งานจริงบนมือถือ ให้เปิด `https://thanakronpart-time.com` ผ่าน Chrome Android หรือ Safari iPhone แล้วติดตั้งเป็น PWA ได้จากเมนูของเบราว์เซอร์

## บัญชีทดสอบ

บัญชีชุดนี้มาจาก `backend/seed.py` ใช้สำหรับทดสอบหรือดูตัวอย่างข้อมูลเท่านั้น

| บทบาท | รหัสเข้าใช้ | รหัสผ่าน | ใช้ดูอะไรได้ |
|---|---|---|---|
| หัวหน้า / ผู้จัดการ | `BOSS001` | `boss12345` | ดูปฏิทินเข้างานของพนักงาน, เลือกพนักงาน/เดือน, ดูประวัติใบหน้าของพนักงาน, ทดสอบ LINE API |
| พนักงาน | `EMP001` | `password123` | ใช้แอปมือถือเช็คอิน/ออกงาน, ดูและบันทึกประวัติใบหน้าของตัวเอง |

ช่องล็อกอินรับได้ทั้งรหัสพนักงานหรืออีเมล แต่แนะนำให้ใช้รหัสพนักงานตามตารางเพื่อหลีกเลี่ยงการเผยแพร่อีเมลจริงในคู่มือ

## วิธีเริ่มระบบบนเครื่องนี้

วิธีง่ายสุดคือเปิดโฟลเดอร์ `checkin-system` แล้วดับเบิลคลิก `START_PART_TIME.bat`

ปุ่มที่ใช้บ่อย:

| ปุ่ม | ความหมาย |
|---|---|
| `รันบนเครื่องนี้` | เปิด backend dev และ frontend dev |
| `หยุดที่รันบนเครื่อง` | ปิด backend/frontend dev |
| `อัปขึ้นเว็บจริง` | build เว็บและอัปเดตระบบ production |
| `เช็คสถานะเว็บจริง` | ตรวจ IIS, backend, Cloudflare Tunnel |
| `เปิดเว็บจริง` | เปิด `https://thanakronpart-time.com` |

ถ้ารันเองผ่าน terminal ให้ดูรายละเอียดเต็มใน `RUN_LOCAL.md`

## วิธีใช้งานสำหรับหัวหน้า

1. เปิด `https://thanakronpart-time.com`
2. เข้าสู่ระบบด้วย `BOSS001` / `boss12345`
3. เข้าหน้า `/` เพื่อดูปฏิทินเข้างาน
4. เลือกพนักงานจากช่อง `พนักงาน`
5. เลือกเดือนจากปฏิทินเพื่อดูเวลาเข้า, เวลาออก, และสถานะว่าอยู่ในเขตออฟฟิศหรือไม่
6. เข้าหน้า `/face-records` เพื่อดูประวัติใบหน้าที่บันทึกไว้
7. กด `ออกจากระบบ` เมื่อใช้งานเสร็จ

หัวหน้าดูข้อมูลรายงานและรายชื่อพนักงานได้ แต่การเช็คอิน/ออกงานจริงยังทำผ่านแอปมือถือหรือ API เช็คอิน

## วิธีใช้งานสำหรับพนักงาน

### ใช้ผ่านแอปมือถือ Flutter

1. เปิดแอป `mardodi_checkin` บนโทรศัพท์
2. เข้าสู่ระบบด้วย `EMP001` / `password123`
3. อนุญาตสิทธิ์ตำแหน่งและกล้องเมื่อเครื่องถาม
4. หน้าแรกจะแสดงว่าอยู่ในเขตเช็คอินหรือไม่
5. ถ้าอยู่ในเขต ให้กด `เข้างาน (สแกนหน้า)` หรือ `ออกงาน (สแกนหน้า)`
6. จัดหน้าให้อยู่ในกล้อง รอให้ระบบขึ้นว่าพร้อม แล้วกดยืนยัน
7. ถ้าบันทึกสำเร็จ แอปจะแสดงหน้า `บันทึกเสร็จแล้ว` พร้อมช่วงเวลา จุดทำงาน และระยะทาง

เงื่อนไขเช็คอิน: ต้องอยู่ในรัศมีสถานที่ที่กำหนด และต้องตรวจพบใบหน้า/liveness ผ่าน

เมื่อ backend บันทึกสำเร็จและตั้งค่า LINE ไว้ครบ ระบบจะส่งข้อความเข้ากลุ่มในรูปแบบ:

`ตอนนี้ฉันได้บันทึกการเข้างานของคุณแล้ว (ช่วงเวลา) ห่างจากจุดทำงาน ระยะทาง`

สถานที่ที่ระบบรู้จักตอนนี้:

| สถานที่ | พิกัด | รัศมี |
|---|---|---|
| `MARDODI` | `13.9231953, 100.5195808` | 2 กม. |
| `BJH Bangkok` | `13.8918358, 100.563443` | 1 กม. |
| `ถึงบ้านแล้ว` | `13.8865664, 100.5066278` | 0.2 กม. หรือ 200 เมตร |

### ใช้ผ่านเว็บ

1. เปิด `https://thanakronpart-time.com`
2. เข้าสู่ระบบด้วยบัญชีพนักงาน
3. หน้า `/` จะแสดงข้อความว่าปฏิทินรวมสำหรับผู้จัดการเท่านั้น
4. เข้า `/face-records` เพื่อบันทึกและดูประวัติใบหน้าของตัวเอง

## Path หน้าเว็บ

| Path | ต้องล็อกอิน | หัวหน้า | พนักงาน | รายละเอียด |
|---|---:|---|---|---|
| `/login` | ไม่ต้อง | เข้าได้ | เข้าได้ | หน้าล็อกอินด้วยรหัสพนักงาน/อีเมลและรหัสผ่าน |
| `/` | ต้อง | ดูปฏิทินรวม เลือกพนักงานและเดือน | เห็นข้อความแจ้งว่าใช้ได้เฉพาะผู้จัดการ | Dashboard ปฏิทินเข้างาน |
| `/face-records` | ต้อง | บันทึกใบหน้าของตัวเอง และเลือกดูประวัติใบหน้าพนักงาน | บันทึกและดูของตัวเองเท่านั้น | หน้าประวัติใบหน้า |
| path อื่น ๆ | แล้วแต่สถานะล็อกอิน | redirect ไป `/` | redirect ไป `/` | React Router ส่งกลับหน้าแรก |

หมายเหตุ: หน้าเว็บใช้ `/face-records` เพราะ `/faces` เป็น path ของ API

## Path API

API ปกติไม่มี `/api` นำหน้า เช่นใช้ `/auth/login` ไม่ใช่ `/api/auth/login` แต่ production ยังรองรับ `/api/...` สำหรับ client เก่าบางตัว

| Method | Path | สิทธิ์ | ใช้ทำอะไร |
|---|---|---|---|
| `GET` | `/health` | ไม่ต้องล็อกอิน | ตรวจว่า backend ยังทำงานอยู่ |
| `GET` | `/` | ไม่ต้องล็อกอินเมื่อเรียก backend ตรง | ดูข้อมูล service และ geofence เบื้องต้น |
| `GET` | `/docs` | ไม่ต้องล็อกอิน | Swagger API docs |
| `GET` | `/redoc` | ไม่ต้องล็อกอิน | ReDoc API docs |
| `GET` | `/openapi.json` | ไม่ต้องล็อกอิน | OpenAPI schema |
| `POST` | `/auth/login` | ไม่ต้องล็อกอิน | เข้าสู่ระบบและรับ JWT token |
| `POST` | `/auth/register` | ไม่ต้องล็อกอิน | สมัครพนักงานหรือผู้จัดการใหม่ |
| `POST` | `/checkins` | ต้องล็อกอิน | เช็คอิน/ออกงาน พร้อมพิกัด, สถานะใบหน้า และรูปถ่าย |
| `GET` | `/checkins/me` | ต้องล็อกอิน | ดูประวัติเช็คอินของตัวเอง |
| `POST` | `/locations/ping` | ต้องล็อกอิน | แอปมือถือส่งพิกัด GPS ต่อเนื่อง |
| `POST` | `/faces/enroll` | ต้องล็อกอิน | บันทึกรูปใบหน้าของผู้ใช้ที่ล็อกอินอยู่ |
| `GET` | `/faces/me` | ต้องล็อกอิน | ดูประวัติใบหน้าของตัวเอง |
| `GET` | `/faces/employee/{employee_id}` | ต้องล็อกอิน | หัวหน้าดูได้ทุกคน, พนักงานดูได้เฉพาะ id ตัวเอง |
| `GET` | `/faces/{record_id}/photo` | ต้องล็อกอิน | ดูรูปใบหน้า เฉพาะเจ้าของรูปหรือหัวหน้า |
| `GET` | `/reports/geofence` | ไม่ต้องล็อกอิน | ดูสถานที่เช็คอินและรัศมีที่อนุญาต |
| `GET` | `/reports/employees` | ต้องเป็นหัวหน้า | ดูรายชื่อพนักงานทั้งหมด |
| `GET` | `/reports/calendar?employee_id={id}&year={yyyy}&month={m}` | ต้องเป็นหัวหน้า | ดูสรุปเข้า/ออกงานรายวันของพนักงานในเดือนที่เลือก |
| `POST` | `/line/webhook` | LINE เรียกเข้าและตรวจ signature | รับ webhook จาก LINE เพื่อหา group id และตอบกลับ |
| `GET` | `/line/status` | ต้องเป็นหัวหน้า | ตรวจสถานะการตั้งค่า LINE โดยไม่โชว์ token เต็ม |
| `POST` | `/line/test` | ต้องเป็นหัวหน้า | ส่งข้อความทดสอบเข้ากลุ่ม LINE |

## โฟลเดอร์สำคัญในโปรเจกต์

| Path ในเครื่อง | รายละเอียด |
|---|---|
| `backend/` | FastAPI backend, database model, API routers, seed data |
| `frontend/` | React/Vite frontend สำหรับหน้าเว็บ |
| `flutter_app/` | แอป Flutter สำหรับพนักงานบนมือถือ |
| `deploy/` | สคริปต์ deploy IIS, Cloudflare Tunnel, LINE |
| `RUN_LOCAL.md` | คู่มือรันระบบบนเครื่องตัวเอง |
| `README.md` | ภาพรวมระบบและคำสั่งหลัก |

## ปัญหาที่พบบ่อย

| อาการ | วิธีตรวจ/แก้ |
|---|---|
| ล็อกอินไม่ได้ | ตรวจว่ารัน backend อยู่ และใช้รหัสตามตารางบัญชีทดสอบ |
| พนักงานเข้า `/` แล้วไม่เห็นปฏิทิน | ปกติของระบบ หน้าปฏิทินรวมจำกัดเฉพาะหัวหน้า |
| กล้องในเว็บเปิดไม่ได้ | ต้องเปิดผ่าน HTTPS บนเว็บจริง หรือ `localhost` ตอน dev และต้องกดอนุญาตสิทธิ์กล้อง |
| เช็คอินไม่ได้เพราะอยู่นอกเขต | ต้องอยู่ในรัศมีสถานที่ที่กำหนดใน `OFFICES` / `Config.offices` |
| แอปมือถือเรียก API ไม่ได้ | ตรวจ `flutter_app/lib/config.dart` ว่า `apiBase` ชี้ backend ที่เข้าถึงได้ |
| เปลี่ยนสถานที่เช็คอินแล้วแอปมือถือแสดงระยะไม่ตรง | แก้ทั้ง `backend/.env` และ `flutter_app/lib/config.dart` แล้ว build แอปใหม่ |
