# Thai address dataset

`thai_addresses.json` is downloaded from
[kongvut/thai-province-data](https://github.com/kongvut/thai-province-data),
file `api/latest/sub_district_with_district_and_province.json`.

- Dataset records: 7,452 subdistricts
- Data version downloaded: 2026-08-26
- Upstream license: MIT
- Upstream copyright: Kongvut Sangkla and contributors

The file is kept locally so address lookup does not depend on GitHub or another
third-party API at runtime.
